## 11. Matriz de profundidad

Cada capacidad pasa por cuatro niveles:

| Nivel | Evidencia |
|---|---|
| L0 — Definida | Problema, owner, entidad, flujo y KPI |
| L1 — Operable | Happy path y excepciones principales ejecutables |
| L2 — Controlada | Permisos, auditoría, reconciliación, SLO y runbook |
| L3 — Inteligente | Diagnóstico, intervención y resultado medido |

No se permite presentar una capacidad L0 como “módulo terminado”.
